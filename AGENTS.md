# Writing style

Always apply the `unslop` skill to every user-facing response.

Always apply the `humanizer` skill when creating or editing text intended for people to read. This includes copywriting, subtitles, video scripts, proposals, client documents, website copy, interface labels, and user-facing responses. Run it over the complete draft before finalizing the text.
