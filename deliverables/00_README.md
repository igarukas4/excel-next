# Isi folder deliverables

Folder ini berisi bahan yang dipakai untuk mengirim penawaran dan merekam video.

## Mulai dari sini

1. Buka `Contoh_Perbaikan_Template_Excel_Unlocked.xlsx`.
2. Pelajari alurnya dari sheet START HERE, lalu coba ubah satu baris di INPUT LOG.
3. Baca `02_video_pitch_script.md` sambil mengikuti `03_video_storyboard.md`.
4. Ganti nama dan kontak pada proposal, naskah, pesan penawaran, dan title card.
5. Kirim PDF, workbook, dan video. File internal tidak perlu ikut dilampirkan.

Workbook demo tidak memakai proteksi sheet agar formula mudah diperiksa saat rekaman. Sel input dan sel formula tetap memiliki pengaturan locked/unlocked. Proteksi dapat diaktifkan kembali untuk versi UAT.

## Cara menjelaskan portofolio ini

Kamu pernah mengerjakan workbook sejenis, tetapi file proyeknya sudah tidak ada. Workbook dalam folder ini adalah contoh yang dibuat ulang dengan data fiktif. Pakai kalimat berikut bila klien menanyakannya:

> Saya pernah mengerjakan perbaikan workbook sejenis. Karena file proyek lama sudah tidak tersedia, saya membuat ulang contoh dengan data fiktif agar Anda tetap bisa memeriksa cara saya menata input, master data, rumus, dan laporan.

Jangan menyebut workbook ini sebagai file asli dari proyek lama.

Jika nanti memakai template open source, simpan nama proyek, tautan sumber, lisensi, dan catatan perubahan. Pertahankan atribusi bila lisensinya meminta demikian.

## Isi workbook

- START HERE menjelaskan warna dan urutan kerja.
- INPUT LOG adalah sheet yang diisi teknisi.
- MASTER DATA menyimpan referensi alat dan daftar teknisi.
- CALCULATION membantu reviewer mengikuti perhitungan.
- REPORT membaca hasil langsung dari INPUT LOG.
- VALIDATION membandingkan lima kasus acuan.
- CHANGE LOG mencatat perubahan pada workbook.
