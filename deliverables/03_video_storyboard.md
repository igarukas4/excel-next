# Urutan rekaman video

Rekam layar pada 1080p. Tutup notifikasi dan file lain yang mungkin menampilkan data pribadi. Atur zoom Excel sekitar 100% supaya isi sel terbaca.

## Urutan gambar

| Waktu | Yang ditampilkan | Yang dilakukan |
|---|---|---|
| 0:00 sampai 0:25 | Kamera atau title card | Perkenalkan diri dan jelaskan bahwa file ini adalah contoh yang dibuat ulang dari pengalaman sebelumnya. |
| 0:25 sampai 0:45 | START HERE | Tunjukkan urutan INPUT LOG, MASTER DATA, CALCULATION, lalu REPORT. |
| 0:45 sampai 1:05 | INPUT LOG | Klik beberapa sel kuning dan jelaskan bahwa hanya sel tersebut yang diisi teknisi. |
| 1:05 sampai 1:25 | INPUT LOG | Pilih Asset ID. Tunggu sampai deskripsi, unit, standar, dan toleransi terisi. |
| 1:25 sampai 1:35 | INPUT LOG | Masukkan nilai di luar toleransi sampai status berubah menjadi REVIEW. |
| 1:35 sampai 1:50 | MASTER DATA | Tunjukkan asal nilai standar dan toleransi. |
| 1:50 sampai 2:10 | CALCULATION | Ikuti satu Work Order dari nilai standar sampai status akhir. |
| 2:10 sampai 2:25 | REPORT | Tunjukkan jumlah PASS, REVIEW, dan daftar pekerjaan. |
| 2:25 sampai 2:40 | VALIDATION | Tunjukkan lima kasus dengan hasil PASS. |
| 2:40 sampai 3:05 | Kamera atau START HERE | Jelaskan langkah kerja dan perkiraan waktu. |

## Baris yang dipakai untuk demo

Pakai satu baris kosong di INPUT LOG.

1. Isi Work Order dengan `WO-DEMO-006`.
2. Pilih tanggal dan teknisi.
3. Pilih Asset ID `AST-004`.
4. Beri waktu sebentar agar kolom referensi terisi.
5. Isi tiga pengukuran yang dekat dengan 25,00 sampai statusnya PASS.
6. Ubah salah satu nilai sampai rata-ratanya melewati toleransi 0,05. Status akan berubah menjadi REVIEW.

Latih bagian input sekali sebelum merekam. Gerakkan pointer dengan pelan dan berhenti sebentar pada angka yang sedang dijelaskan.

Saat berbicara, bedakan pengalaman lama dan file demo dengan jelas. Gunakan "pernah saya kerjakan" untuk pengalamannya dan "contoh ini" untuk workbook yang terlihat di layar. Hindari angka penghematan waktu karena workbook klien belum diperiksa.
